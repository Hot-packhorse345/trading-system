## 🚀 Setting Up Your First Strategy

The software allows you to build rules for trading without manual intervention.

### Connect to an Exchange
You must connect your account from Binance or MetaTrader 5 to the system. 
1. Open the Settings menu inside the application.
2. Select the Exchange tab.
3. Choose your provider from the list.
4. Enter your API key and secret key provided by your exchange account.
5. Click Save to store your credentials.

### Create a Strategy
A strategy tells the software when to buy or sell. 
1. Go to the Strategy Editor tab.
2. Choose a new empty project.
3. Input your parameters, such as entry price, exit price, and stop-loss limits.
4. Select the asset pair you want to trade.
5. Save your strategy.

### Run a Test
Always test your strategy before you use real money. This creates a simulation using historical market data. 
1. Select the Backtest tool from the main dashboard.
2. Pick the strategy you created.
3. Choose the time frame you want to test.
4. Click the Run Test button.
5. Review the performance report to see how your rules would have performed in the past.

## 🛡 Security Guidelines

Protecting your accounts is vital when using automated trading software.

*   Keep your API keys confidential. Do not share them with anyone.
*   Enable two-factor authentication on your exchange account.
*   Set withdrawal permissions to off within your exchange API settings. This prevents the software from moving funds out of your account.
*   Monitor the application regularly while it runs live strategies.

## ❓ Troubleshooting Common Issues

If the software does not work as expected, check these common items:

*   Application will not open: Verify you have administrative rights on your Windows account. Check that your antivirus software is not blocking the program.
*   Connection failed: Verify your internet connection. Check that your API keys are correct. Ensure your exchange account has active API permissions.
*   Performance lag: Close other programs to free up system memory. Ensure you test strategies on a stable internet connection.
*   Data not loading: Check the exchange status page. Servers sometimes go offline for maintenance. 

If issues persist, restart your computer and try again. Ensure you have the latest software updates installed. You can check for updates by clicking the Help menu inside the application.

## 📖 Glossary of Terms

*   Backtesting: Testing a strategy using past market data.
*   API Key: A unique code that allows the software to talk to your exchange account.
*   Stop-loss: A rule that sells an asset once it hits a certain price to prevent further loss.
*   Asset Pair: Two currencies or assets traded against each other, such as Bitcoin and the US Dollar.
*   Simulation: A mode where you practice trading without using your actual money.
